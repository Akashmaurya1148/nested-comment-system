Project: Nested Commenting System

 Approach

This project implements a full-stack commenting system with authentication, nesting and upvotes.
The backend is built with Express.js and Prisma ORM, and the frontend uses Next.js + Tailwind CSS.


Core features:

User Registration & Login (JWT)

Post Comments and Replies (nested)

View Replies for Any Comment

Upvote Comments


Responsive, animated UI with Tailwind

 Tech Stack

Frontend: React, TypeScript, Tailwind CSS

Backend: Express.js, Prisma ORM


Auth: JWT-based Authentication

Deployment: Vercel (frontend), Render/Railway (backend)
